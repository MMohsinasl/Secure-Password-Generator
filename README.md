# Secure Password Generator

## Overview
This Python tool generates strong, random passwords suitable for securing accounts and sensitive data.  
It also allows hashing the generated password using **SHA-256** or **bcrypt** for added security.

## Features
- Customizable password length
- Include uppercase letters, digits, and symbols
- Hash the generated password using SHA-256 or bcrypt
- Educational: demonstrates cryptography and secure password practices
